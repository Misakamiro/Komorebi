# Komorebi Notices

Komorebi is a Windows-first desktop media conversion application built from FFBox 5.0+.

- FFBox source: https://github.com/ttqftech/FFBox
- FFmpeg source and project: https://ffmpeg.org/
- ncmdump source: https://github.com/taurusxin/ncmdump
- Bundled FFmpeg binaries: Windows amd64 full build available on this machine
- Bundled ncmdump binary: ncmdump 1.5.1 Windows amd64 release

Komorebi-specific licensing and attribution are described in `LICENSE`. The original FFBox license and terms are preserved in `licenses/FFBox-LICENSE.txt`. Bundled FFmpeg licensing information is included as `tools/LICENSE-ffmpeg.txt` and `tools/README-ffmpeg.txt`. The bundled ncmdump command line binary is distributed under the upstream MIT license included as `tools/LICENSE-ncmdump.txt`.
